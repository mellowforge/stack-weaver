First public release.

`@stack-weaver/core` is a schema-driven visual and code editor for Kubernetes and docker-compose YAML. `createManifestEditor(el, options)` mounts a Visual, Split or Code editor over one shared document model, so an edit in either pane shows up in the other and undo and redo span both. Edits change only the lines they touch: comments, key order and untouched lines stay byte for byte, CRLF included. The visual pane has an outline tree, schema-driven field widgets (including references between resources and a decoded Secret `data` editor), an "Add resource" picker, starter recipes for an empty document and a banner for broken YAML. The code pane uses a CodeMirror 6 adapter at `@stack-weaver/core/editors/codemirror` (CodeMirror packages and `@lezer/highlight` are peer dependencies; bring your own through the `CodeEditorAdapter` interface). Compose variables (`${VAR}` with `:-`, `-`, `:?`, `?`, `:+` and `+`) are declared in a top-level `x-variables:` block or in a list the host owns, with a Variables section and a "Use variable" toggle on each field. Semantic rules and one-click quick fixes run after schema validation (Kubernetes `service-selector`, `selector-mismatch`, `missing-resources` and `target-port`; compose `undeclared-variable`, `variable-default`, `variable-declaration` and `variable-type`). Style it with `@stack-weaver/core/stack-weaver.css` and its `--sw-*` tokens, switch themes with `theme`, and translate it with `messages.ui` and `messages.schema`. The controller offers `update(patch)`, `setFormat`, `getActiveFormat`, `applyFix`, `reset`, `clearHistory`, `canUndo` and `canRedo`, and the options `onFormatChange` and `onHistoryChange` report the resolved format and the history state (a `HistoryState`, exported as a type). Custom formats, guides, widgets, recipes and code editors plug in through the public registries and options.

`@stack-weaver/react` provides `<ManifestEditor>`, the core editor with props in place of options and setters, for React 19. It is safe under `<StrictMode>` and server rendering. `value` (or `defaultValue`) and `onChange` carry the text and the change origin, `mode` and `onModeChange` the pane layout, `format` the format option with `onFormatChange` reporting the active format, and `readOnly`, `theme` and `variables` configure the editor. `onProblemsChange`, `onVariablesChange` and `onHistoryChange` report its state, and `ref` is the live `ManifestEditorController`. Init-only options recreate the editor when their reference changes; the settable ones are pushed without calling `onChange` or `onModeChange`. It re-exports the core types its props use (`ManifestEditorOptions`, `HistoryState`, `EditorMessages`, `GuideOverride`, `WidgetRegistry`, `WidgetDefinition`, `CodeEditorAdapter`, `SyncCodeEditorAdapter` and more).

`@stack-weaver/angular` provides the standalone `<sw-manifest-editor>` component (`SwManifestEditor`) for Angular 22, with and without zone.js. It takes `[(value)]`, `[(mode)]`, `[format]`, `readOnly`, `theme` and `variables`, and emits `problemsChange`, `variablesChange`, `activeFormatChange`, `historyChange` and `textChange` (`{ value, origin }`). `controller()` returns the live `ManifestEditorController`. Init-only options recreate the editor when their reference changes; the settable ones are pushed without emitting `textChange`, `valueChange` or `modeChange`. It re-exports the same core types as the React package.
